# Agent instructions

For work on BYU Office of Research Computing systems, read and follow
[`BYU_ORC_AGENTS.md`](BYU_ORC_AGENTS.md) before inspecting project data or
making changes. The copy in this repository should be refreshed from
`/apps/instructions_for_ai_agents/BYU_ORC_AGENTS.md` when older than seven days.

The `BOTQ_2026` project uses dated public equity and inflation data. Do not
commit downloaded data, environment files, credentials, or generated runs.
